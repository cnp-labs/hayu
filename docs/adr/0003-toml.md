# ADR-0003 — TOML as the primary configuration format

Date: November 2, 2026. Status: **user-decided**; schema/state details are proposals.

## Decision

Declare Hayu settings through TOML. Defer Lua/runtime scripting until a concrete need exists. Configuration files do not execute scripts.

## Reasons and consequences

A typed schema supports validation, defaults, errors, and transactional reload. There are no user functions/loops; future dynamic extensions need a separate API. Configuration format does not justify performance claims.

## Contract and validation

Defaults → one config → supported CLI; no hidden GUI overrides. Unknown keys/invalid schema reject the candidate and preserve last-known-good. Separate state/cache. M1 tests parsing, semantic validation, atomic rename, rollback, and reload lifecycle. Schema evolution needs explicit versioning/migration.
